## 3D Flipbook & Documentation Publishing: Hong Kong engineering firm, 2026

**Problem:** Company publications were only available as PDF downloads. Engineering documentation also needed a repeatable way to reach SharePoint.

**My role:** I built the viewer, the publishing pipeline and the cloud deployment.

**Scope**
- An in-browser 3D flipbook reader that works on desktop and mobile.
- An admin upload flow that turns PDFs into published flipbooks.
- A docs-as-code workflow that publishes print-ready documentation to SharePoint.

**Outcome:** publications can now be read in the browser instead of downloaded, and documentation reaches SharePoint through a repeatable automated workflow.

**Stack:** Vue, Three.js (WebGL) · Node.js · Python · Docker · Google Cloud · GitHub Actions
